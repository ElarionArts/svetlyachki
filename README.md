# Fireflies: Light Puzzle · Светлячки: головоломка

A logic puzzle for Android by **ElarionArts**.

Tap a cell to switch it along with its neighbours above, below, left and right. Light up every firefly before you run out of moves.

- 150 levels, from a 3×3 warm-up to tricky 7×7 boards
- Three stars for solving in the minimum number of moves
- Hints that show a move from the shortest solution
- Plays offline, no sign-up

## На русском

**Светлячки** — логическая игра для Android от **ElarionArts**.

Нажатие на клетку переключает её и соседей сверху, снизу, слева и справа. Зажгите всех светлячков, пока не закончились ходы.

- 150 уровней — от разминки 3×3 до сложных полей 7×7
- Три звезды за решение в минимальное число ходов
- Подсказки показывают ход из кратчайшего решения
- Играйте без интернета и без регистрации
